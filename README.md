# Task-Solitaire

Реализовать минимальный прототип пасьянса с возможностью перетаскивания карт по следующим правилам:

Колода 
    
    Содержит 52 карты (можно использовать заглушки: просто спрайт) 
    Карты хранятся в стеке (LIFO): последняя добавленная — сверху.    
    Карты перетаскиваются драг энд дропом левой кнопкой мыши.
    
Стопка-приёмник 
        
    Представляет собой 4 пустых места под карты
    В эту стопку можно класть только по одной карте.
    Карты накладываются строго одна на другую (без смещения).
    Нельзя перетаскивать туда часть "лесенки".(3)
    
Игровые стопки (лесенки) 
        
    Представляют собой набор карт, аналогичный референсу
    Карты в стопке отображаются "лесенкой": каждая следующая карта смещена вниз на фиксированное значение
    Можно перетаскивать любую подстопку (часть лесенки начиная с выбранной карты до конца стопки) на другую игровую стопку.
    Перетаскивание на Стопку приемник (2) только по одной карте.
    
Дополнительно:

Переворачивать карты не нужно — все карты лежат рубашкой вверх.

Логика проверки "можно ли положить" (масть, порядок) не требуется — любые карты можно класть куда угодно.

Главное — корректная работа механики перетаскивания и адаптивный UI.
