# Task-Solitaire

Минимальный прототип пасьянса на **Unity 2022.3.62f2** и **C#**, посвящённый перетаскиванию карт и работе с UI-стопками. Можно перемещать отдельные карты и части «лесенки», а при недопустимом сбросе карты возвращаются на исходное место.

Все карты отображаются рубашкой вверх. Проверка масти и ранга, переворот карт и условие победы не входят в текущую реализацию.

## Возможности

- Создание 52 карт и автоматическая начальная раздача.
- Перетаскивание левой кнопкой мыши.
- Три типа стопок: колода, игровые «лесенки» и стопки-приёмники.
- Перенос части лесенки с сохранением порядка карт.
- Возврат перемещаемой группы при сбросе за пределами стопки или на неподходящую стопку.
- Настройка количества карт, начальной раскладки и оформления через ScriptableObject.
- UI на Unity UI (uGUI), с якорями RectTransform и Canvas Scaler.

## Быстрый запуск

1. Установите **Unity Hub** и редактор **Unity 2022.3.62f2** — эта версия указана в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
2. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Dalon11/Task-Solitaire.git
   ```

3. Добавьте папку `Task-Solitaire` в Unity Hub как существующий проект и откройте её.
4. Дождитесь импорта ресурсов и восстановления пакетов из [Packages/manifest.json](Packages/manifest.json).
5. Откройте сцену [Assets/Scenes/SampleScene.unity](Assets/Scenes/SampleScene.unity).
6. Нажмите **Play** и перейдите в окно **Game**.

Сцена уже содержит игровой Canvas и EventSystem. Начальная раздача выполняется автоматически в `DealController.Start()`.

### Начальное состояние

В сохранённой конфигурации проекта:

| Область | Количество | Карты после раздачи |
| --- | --- | --- |
| Колода | 1 | 42 карты |
| Игровые лесенки | 4 | 1, 2, 3 и 4 карты |
| Стопки-приёмники | 4 | Пустые |

Всего создаётся 52 карты: 10 раздаются по лесенкам, остальные остаются в колоде.

## Управление и правила

Зажмите **левую кнопку мыши** на карте, перетащите её на целевую стопку и отпустите кнопку.

| Тип стопки | Что можно взять | Что можно положить |
| --- | --- | --- |
| Колода (`DeckPile`) | Только верхнюю карту, по принципу LIFO | Перенос из других стопок запрещён |
| Лесенка (`CascadePile`) | Выбранную карту и все карты после неё в стопке | Одну карту или любую непустую группу |
| Приёмник (`FoundationPile`) | Только верхнюю карту | Ровно одну карту за перенос |

- В колоде и приёмниках карты лежат строго друг на друге, без смещения.
- В лесенке каждая следующая карта смещена вниз. Шаг вычисляется как высота карты × `_verticalSpacingRatio`; в префабе задано `0.1`.
- Чтобы перенести карту из лесенки в приёмник, выберите её последнюю, нижнюю карту. Выбор более ранней карты захватывает также все следующие за ней карты.
- Приёмник может накапливать несколько карт, но принимает их только по одной.
- Если отпустить карты вне стопки, перенести группу в приёмник или попытаться положить карты в колоду, они вернутся в исходную стопку.
- Масть, цвет и порядок рангов не проверяются.

Для повторной начальной раздачи остановите **Play Mode** и запустите его снова.

### Основные компоненты

| Компонент | Ответственность |
| --- | --- |
| [CardView](Assets/Feature/Card/CardView.cs) | Спрайт, размер, положение карты, текущая стопка и блокировка raycast |
| [PileBase](Assets/Feature/Piles/Abstractions/PileBase.cs) | Хранение карт в списке, извлечение группы и общие операции со стопкой |
| [DeckPile](Assets/Feature/Piles/DeckPile.cs), [CascadePile](Assets/Feature/Piles/CascadePile.cs), [FoundationPile](Assets/Feature/Piles/FoundationPile.cs) | Правила взятия, размещения и раскладки карт |
| [DealController](Assets/Feature/Deal/DealController.cs) | Создание карт из префаба и раздача по заданной конфигурации |
| [DragController](Assets/Feature/Drag/DragController.cs) | Обработка нажатия, удержания и отпускания кнопки мыши |
| [DragSession](Assets/Feature/Drag/DragSession.cs) | Перенос группы в DragLayer, движение, завершение или возврат |
| [UiRaycast](Assets/Feature/Drag/UiRaycast.cs) | Поиск карты и целевой стопки под курсором |

При начале переноса группа извлекается из исходной стопки и помещается в `DragLayer`. На время движения карты перестают блокировать raycast. При отпускании кнопки проверяется `CanDrop()` целевой стопки; затем группа добавляется в неё либо возвращается в источник, и раскладка обновляется.

## Настройка

Существующие конфигурации находятся в [Assets/Game/SO](Assets/Game/SO). Новые можно создать через **Assets → Create → Solitaire**.

| Конфигурация | Назначение |
| --- | --- |
| `DeckModel` | `_suitsCount × _ranksCount` задаёт общее число карт. Сейчас `4 × 13 = 52`; индивидуальные масти и ранги карт не хранятся |
| `CascadeLayoutModel` | `_columnCardCounts` задаёт число карт в каждой лесенке. В сохранённом asset: `[1, 2, 3, 4]` |
| `DealConfig` | Объединяет модели колоды и раскладки, префаб карты и спрайт рубашки |

При изменении раскладки задайте неотрицательные количества и оставьте в списке как минимум по одному значению на каждую лесенку из `DealController._cascadePiles`. Чтобы полностью выполнить раздачу, сумма используемых значений не должна превышать число карт в колоде.

Значения по умолчанию в классе `CascadeLayoutModel` — `[3, 4, 5, 6]`; основная сцена использует сохранённый asset с `[1, 2, 3, 4]`.

### Интерфейс и ввод

Основной UI находится в [PatienceCanvas.prefab](Assets/Game/Prefabs/UI/PatienceCanvas.prefab):

- Canvas работает в режиме **Screen Space — Overlay**.
- Canvas Scaler использует **Scale With Screen Size**, опорное разрешение **1920 × 1080** и `Match Width Or Height = 0.5`.
- Отступ лесенки настраивается в компоненте `CascadePile`.
- Ввод использует `UnityEngine.Input` и старый Input Manager; отдельный пакет Input System не требуется.

Обработчик пересчёта раскладки при изменении размеров `RectTransform` в `PileBase` закомментирован. При проверке разных разрешений учитывайте, что шаг лесенки пересчитывается при раздаче и завершении переноса, а не автоматически при каждом изменении размера окна.

## Сборка

1. Откройте **File → Build Settings**.
2. Убедитесь, что `Assets/Scenes/SampleScene.unity` включена в **Scenes In Build** — она уже добавлена в настройки репозитория.
3. Выберите целевую платформу и установите необходимый модуль сборки через Unity Hub.
4. Нажмите **Build** или **Build And Run**.

Текущее управление реализовано для мыши. Отдельное сенсорное управление в проекте не реализовано.

## Проверка механики

В репозитории подключён Unity Test Framework, но автоматических тестов нет. Для ручной проверки:

1. Запустите сцену: должны появиться четыре лесенки по 1–4 карты и четыре пустых приёмника.
2. Перенесите верхнюю карту из колоды в лесенку и в приёмник.
3. Перенесите часть лесенки в другую лесенку: порядок карт должен сохраниться.
4. Попробуйте перенести группу из нескольких карт в приёмник: группа должна вернуться.
5. Отпустите карту вне стопок и над колодой: она должна вернуться в источник.
6. Перенесите верхнюю карту из приёмника обратно в лесенку.
7. Проверьте интерфейс при разных разрешениях окна Game.

## Границы прототипа

Проект демонстрирует механику drag-and-drop из исходного задания. Полные правила пасьянса, переворот карт, подсчёт очков, проверка победы, отмена ходов и сохранение партии не реализованы.
